# PRISM
Personalized Responsive Intelligent Simplification Module \
PRISM is an AI-driven adaptive learning system specifically engineered for students with ADHD in grades 5–10. By leveraging Natural Language Processing (NLP) and Generative AI, the platform "refactors" complex curriculum content into multiple formats to reduce cognitive overload and enhance conceptual comprehension.

# Core Features
- Focus Mode (NLP): Automatically simplifies academic jargon and breaks dense paragraphs into manageable "information chunks" using Transformer models.
- Audio Mode (TTS): Converts simplified content into high-quality speech with adjustable playback speeds to support auditory learners.
- Visual Mode (Gen-AI): Uses Generative AI to create contextual images and visual metaphors for abstract concepts in Science and Social Studies.
- Distraction-Free UI: A minimalist, responsive interface designed to prevent sensory overload and keep students on task.
