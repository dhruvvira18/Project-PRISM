# PRISM
Personalized Responsive Intelligent Simplification Module \
PRISM is an AI-driven adaptive learning system specifically engineered for students with ADHD in grades 5–10. By leveraging Natural Language Processing (NLP) and Generative AI, the platform "refactors" complex curriculum content into multiple formats to reduce cognitive overload and enhance conceptual comprehension.

# Core Features (Expert-Validated)
- **Unified Concept Cards**: Instead of separate modes, PRISM presents a single "Concept Card" containing text, audio, and visuals simultaneously to reduce task-switching.
- **Cognitive Chunking**: Gemini-powered NLP breaks dense curriculum into exactly 3 bullet points to stay within the ADHD "attention window."
- **Literal Visual Scaffolding**: Generates low-distraction, high-contrast imagery to anchor abstract concepts.
- **Pastel-Calm UI**: A theme based on soft Sage and Cream tones to minimize sensory overstimulation.
